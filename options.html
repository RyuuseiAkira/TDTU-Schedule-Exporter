🎨 Màu theo môn học

Mã môn là số sau "Ma:" trong mô tả sự kiện. Chọn màu bằng cách bấm vào chấm tròn.

📅 Lớp học

Bật: lớp giáo viên báo vắng bị ẩn khỏi popup, không xuất / đồng bộ, và lần đồng bộ Google Calendar kế tiếp sẽ xoá sự kiện cũ của lớp đó. Tắt: vẫn xuất, ghi chú “GV báo vắng” nằm trong mô tả.

🚫 Blacklist

Môn trong danh sách này bị ẩn khỏi popup và không xuất ra .ics / Excel / Google Calendar. Nhập mã môn (ví dụ 000000) hoặc từ khoá trong tên môn (ví dụ tiếng anh).

☁️ Google Calendar

Cần để đồng bộ có màu (Google bỏ qua màu khi import file .ics).

  1. Vào console.cloud.google.com → tạo project.
  2. APIs & Services → Library → bật Google Calendar API.
  3. OAuth consent screen → External → thêm email của bạn vào Test users.
  4. Credentials → Create → OAuth client ID → loại Web application → dán Redirect URI ở trên.
  5. Copy Client ID dán vào ô phía trên.
