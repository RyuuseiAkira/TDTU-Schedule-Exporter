Appearance

Automatically disabled when your system requests reduced motion.

Subject colors

Find the subject code after “Mã:” in the event description. Select a circle to assign a color.

Class filters

When enabled, classes with an absent lecturer are hidden and excluded from exports. The next Calendar sync removes their old events. Otherwise, they remain with an absence note.

Hidden subjects

Hidden subjects are excluded from exports and sync. Enter a subject code (e.g. 000000) or a keyword from its name (e.g. tiếng anh).

Connect Google Calendar

Connect to sync subject colors. Google ignores colors when importing ICS files.

Get a Google OAuth Client ID One-time setup
  1. Open console.cloud.google.com → create a project.
  2. APIs & Services → Library → enable Google Calendar API.
  3. OAuth consent screen → External → add your email to Test users.
  4. Credentials → Create → OAuth client ID → select Web application → paste the Redirect URI above.
  5. Copy your Client ID and paste it into the field above.
